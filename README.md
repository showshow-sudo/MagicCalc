## 🎭 魔术表演脚本（按键顺序）

为了保证表演成功，请魔术师严格遵守以下 **“黄金序列”**：

### 0. 幕后准备
点击计算器左上角隐藏的 **🕒 (时间图标)**，设置你的 **目标数字 T**（例如：`2026`）。

### 1. 第一阶段：真实计算 (建立信任)
1. 邀请观众 A 输入一个数字（如 `50`），点击 **`+`**。
2. 邀请观众 B 输入一个数字（如 `100`），点击 **`=`**。
3. **现象**：屏幕显示 `150`，上方过程显示 `50 + 100 =`。此时逻辑完全真实。

### 2. 第二阶段：布置陷阱 (关键动作)
* 在结果 `150` 之后，魔术师接过手机，**再次点击一下 `+` 号**。
* **现象**：上方过程变为 `150 +`。陷阱已激活，此时可以把手机交给观众。

### 3. 第三阶段：盲操劫持 (观众互动)
* 手机倒扣或装进口袋，邀请观众随便点击几个按键（除等号外）。
* **现象**：无论按什么，计算器会自动跳出差额（如 `1876`）。
* **保护机制**：系统已锁定，观众无论误触多少次，数字都不会再变，完美防穿帮。

### 4. 第四阶段：奇迹时刻
* 拿回手机，按下最后的 **`=`**。
* **结果**：屏幕跳出预设的 **`2026`**！

## ⚠️ 避坑指南（必看）

* **数值安全区**：请确保预设的目标数字 $T$ 比较大（建议 1000 以上）。
* **限制输入**：请引导前两个观众输入较小的数字。
* **逻辑核心**：如果观众输入的 $A+B$ 超过了 $T$，第三个数会出现负号导致穿帮。

## 🛠 技术实现 (Engineering Notes)

* **有限状态机 (FSM)**：通过 `INIT`, `MAGIC_READY`, `MAGIC_FIXED` 等状态流转管理复杂的魔术逻辑。
* **事件劫持**：拦截用户输入流并根据系统状态进行动态补偿计算。
* **幂等性设计**：通过状态锁定防止重复点击导致的逻辑错误。
